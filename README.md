# WEST demo projects

Demo sites for WEST (Wright Energy Storage Technologies). Each project lives in its own folder and deploys as its own Vercel project, with that folder set as the **Root Directory**.

| Project | Folder | What it is |
| --- | --- | --- |
| Storage skid | [`storage-skid/`](storage-skid/) | Single-page site for the containerised storage skid, with an interactive 3D model, Envoy module specs and a string builder |
